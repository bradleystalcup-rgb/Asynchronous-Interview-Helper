# Agent Instructions

## App

This is a Next.js App Router project for a local-only in-browser teleprompter and video recorder.

## Next.js

This project targets Next.js 16. Before changing framework-specific code, read the relevant guide in `node_modules/next/dist/docs/`.

## Verification

- After production-affecting changes, run `npm run build`.
- For UI/media changes, manually verify camera permission, recording, playback, downloaded WebM audio, downloaded WebM filter output, paragraph stepping, and autoscroll.
